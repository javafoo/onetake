# Bundled fonts

Every face here is openly licensed and may be redistributed with this app and
used to render artwork. Keep this list in step with `src/carousel/kits.ts` and
`src/reel/overlay.ts`. Each font's licence travels with it, as the SIL Open
Font License requires.

| File | Family | Licence | Licence file | Used by |
|---|---|---|---|---|
| `TikTokSans-Variable.ttf` | TikTok Sans | SIL Open Font License 1.1 | `OFL-tiktoksans.txt` | reel overlays (bold, pastel, boxed); titles and body in Bold, Bold box, Pastel |
| `EBGaramond-Variable.ttf` | EB Garamond | SIL Open Font License 1.1 | `OFL-ebgaramond.txt` | reel overlays (serif, serif box); titles and body in Serif, Serif box |
| `Inter-Variable.ttf` | Inter | SIL Open Font License 1.1 | `OFL-inter.txt` | body text in Signal, Atelier, Notebook; titles in Notebook; fallback for reel overlays |
| `ArchivoBlack-Regular.ttf` | Archivo Black | SIL Open Font License 1.1 | `OFL-archivoblack.txt` | Signal titles |
| `InstrumentSerif-Regular.ttf`, `InstrumentSerif-Italic.ttf` | Instrument Serif | SIL Open Font License 1.1 | `OFL-instrumentserif.txt` | Atelier titles and accents |
| `PlayfairDisplay-Italic-Variable.ttf` | Playfair Display Italic | SIL Open Font License 1.1 | `OFL-playfairdisplay.txt` | Atelier emphasis and accent |
| `Caveat-Variable.ttf` | Caveat | SIL Open Font License 1.1 | `OFL-caveat.txt` | Notebook accent line |

The licence files are the ones published with each family in
github.com/google/fonts. The OFL does not restrict what is rendered with the
fonts. No face here is licensed per seat or per view.
